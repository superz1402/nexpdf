# NexPDF

Ultimate open-source PDF app for Android — Kotlin + Jetpack Compose + Material 3.

## Status

v0.1 increment: Home library (search, MediaStore + SAF picker) and PDF viewer (lazy PdfRenderer pages). Builds run in GitHub Actions; APK artifact `nexpdf-debug-apk` on every run.

## Roadmap

- Tools: merge, split, rotate, organize pages, images→PDF, extract text (pdfbox-android)
- Annotate, Fill & Sign
- Material 3 Expressive motion pass
- OCR / conversion (later)
